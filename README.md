# TC ⚽

> Uma aplicação moderna e elegante construída com Next.js 15, React 19 e TypeScript

## ✨ Características

- 🚀 **Next.js 15** com Turbopack para desenvolvimento ultra-rápido
- ⚛️ **React 19** com as últimas funcionalidades
- 🎨 **Tailwind CSS** para estilização moderna e responsiva
- 🧩 **Radix UI** - Componentes acessíveis e customizáveis
- 📊 **Visualização de Dados** com Recharts
- 🎯 **TypeScript** para desenvolvimento type-safe
- 🔐 **Iron Session** para gerenciamento de sessões seguro
- 🗄️ **PostgreSQL** para banco de dados robusto
- 📅 **Date-fns** para manipulação de datas
- ✅ **Validação** com Zod e React Hook Form

## 🚀 Começando

### Pré-requisitos

- Node.js (versão 20 ou superior)
- npm ou yarn
- PostgreSQL

### Instalação

```bash
# Clone o repositório
git clone https://github.com/icardogoat/TC.git

# Entre no diretório
cd TC

# Instale as dependências
npm install

# Configure as variáveis de ambiente
cp .env.example .env
# Edite o arquivo .env com suas configurações
```

### Executando em Desenvolvimento

```bash
# Inicie o servidor de desenvolvimento
npm run dev
```

Acesse [http://localhost:9002](http://localhost:9002) para ver a aplicação.

## 📜 Scripts Disponíveis

```bash
npm run dev        # Inicia o servidor de desenvolvimento
npm run build      # Cria o build de produção
npm start          # Inicia o servidor de produção
npm run lint       # Executa o linter
npm run typecheck  # Verifica os tipos TypeScript
```

## 🛠️ Tecnologias

- **Framework:** Next.js 15
- **UI Library:** React 19
- **Linguagem:** TypeScript

- **Formulários:** React Hook Form
